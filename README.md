## About

Hi, I'm **eternal.** I build software, experiment with ideas, and learn
by making things.

Most of my work revolves around creating applications and tools,
experimenting with interfaces, and modifying or extending existing
software. I enjoy moving between different kinds of projects rather than
sticking to one particular stack.

A few areas you'll find across my repositories:

-   Desktop and web applications
-   Command-line tools and utilities
-   Game modding and gameplay experiments
-   Apple platform and cross-platform application experiments

## Tools & technologies

I choose tools based on what a project needs. Across my repositories and
experiments, that includes:

-   **Languages:** JavaScript, Python, PHP, Rust, C/C++ and web
    technologies
-   **Application development:** Electron, Swift, SwiftUI
-   **Platforms:** Linux, Windows, macOS and iOS
-   **Other interests:** Git, terminal tooling, game engines and modding
    toolchains

This is a snapshot of technologies I work with or explore, not a claim
of equal experience with every item.

## Word on AI-assisted development

I use AI tools as part of my development workflow. They can help me
brainstorm, understand unfamiliar code, explore implementations, debug
issues, write boilerplate and improve documentation. I know stuff about it is controversial
and I'd rather be transparent about it. It genuinely helps me put any weird experiment idea into life.

These are merely just tools for me, myself, and I do it because I love developing weird ideas.
